# Housing & Roommate Platform Backend 🏠

A robust, scalable, and secure RESTful backend API for managing properties, rooms, roommate matching, rental bookings, Stripe payments, and maintenance requests.

## 🚀 Tech Stack
- **Runtime**: Node.js
- **Framework**: Express.js with TypeScript
- **Database**: PostgreSQL (Neon Serverless)
- **ORM**: Prisma ORM
- **Validation**: Zod
- **Authentication**: JWT & Google OAuth 2.0 (GCP)
- **Payment Processing**: Stripe Payment Gateway
- **Documentation**: Swagger / OpenAPI & Postman

## 👥 Roles & Authorization
- **ADMIN**: Platform management, user moderation, analytics, listings approval.
- **LANDLORD**: Property and room listings, booking approval/rejection, maintenance management.
- **TENANT**: Search listings, roommate matching, booking requests, Stripe payments, maintenance tickets, reviews.
